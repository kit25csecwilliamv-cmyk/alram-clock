⏰ Professional Alarm Clock

A simple desktop Alarm Clock application built using Python.

✨ Features

- 🕐 Digital clock with AM/PM
- 📅 Current date
- ⏰ Multiple alarms
- 🔔 Alarm sound
- 🛑 Stop alarm
- 😴 Snooze
- 🔘 Enable / Disable alarms
- 🗑️ Delete alarms

🛠️ Technologies

- Python
- Tkinter
- Pygame

📁 Project Structure

alarm-clock/
├── main.py
├── alarm_manager.py
├── sound_manager.py
├── requirements.txt
└── sounds/
    └── alarm1.mp3

🚀 Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Go into the project folder:

cd alarm-clock

Install the required package:

pip install -r requirements.txt

▶️ Run the Application

python main.py

🔊 Alarm Sound

Place your alarm sound file inside:

sounds/alarm1.mp3
